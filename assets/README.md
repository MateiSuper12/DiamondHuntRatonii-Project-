# Game images

The three uploaded image files are currently in the repository root and the game loads them from there. GitHub's available file-edit operation cannot move binary image files; move these files into this folder in the GitHub web UI, then update the paths in `script.js` to `assets/26262708.png`, `assets/Diamond_JE3_BE3.png`, and `assets/Emerald_JE3_BE3.webp`:

- `26262708.png`
- `Diamond_JE3_BE3.png`
